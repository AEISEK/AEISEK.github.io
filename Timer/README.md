# TIMER PRO — Эстетичный таймер и сервис обратного отсчета

Современный, быстрый и минималистичный веб-сервис с таймером обратного отсчета и отсчетом до важных событий. Не требует сборщиков или внешних зависимостей: готов к запуску прямо из папки.

---

## ✨ Возможности

1. **⏱ Таймер длительности (Focus / Pomodoro)**
   - Выбор любого времени: часы, минуты, секунды.
   - Быстрые пресеты в один клик: *1 мин*, *5 мин (короткий перерыв)*, *10 мин*, *15 мин*, *25 мин (Помодоро)*, *45 мин*, *1 час*.
   - Кнопки быстрой коррекции времени прямо на лету: `+1 мин`, `+5 мин`, `+10 мин`.
   - Редактируемое название задачи / фокуса прямо на экране.
   - Прямой ввод времени по клику на цифры с клавиатуры или прокруткой колесика мыши.
   - Плавная линейная полоса прогресса с неоновым градиентом.
   - Расчет точного расчетного времени окончания (например: *«завершится в 14:25»*).

2. **📅 Отсчет до конкретной даты и события (Event Countdown)**
   - Выбор целевой даты и времени (год, месяц, день, часы, минуты).
   - Индивидуальное название события (например: *«Новый Год»*, *«Дедлайн проекта»*, *«Отпуск»*).
   - Четкие плитки обратного отсчета: **Дней**, **Часов**, **Минут**, **Секунд**.
   - Сохранение выбранного события в `localStorage`.

3. **🎨 Премиальный визуальный стиль**
   - Темная тема (Midnight Slate с неоновым свечением) и Светлая тема (Editorial warm bone).
   - Моноширинные цифры (`JetBrains Mono` / Tabular figures), предотвращающие скачки шрифта при смене секунд.
   - Полноэкранный режим Zen (F11 или клавиша `F`): скрывает лишний интерфейс и оставляет только парящие часы.
   - Праздничный салют конфетти (Canvas) по завершении отсчета.

4. **🔔 Звук и Уведомления**
   - Собственный синтезатор гармонического тибетского гонга через **Web Audio API** (без внешних аудиофайлов, работает 100% автономно).
   - Переключатель тихого тиканья секунд.
   - Поддержка браузерных Web Notifications при завершении таймера.
   - Индикация оставшегося времени в заголовке вкладки браузера.

5. **⌨️ Горячие клавиши (Hotkeys)**
   - `Space` (Пробел) — Старт / Пауза
   - `R` — Сбросить таймер
   - `F` — Полноэкранный режим
   - `M` — Включить / Выключить звук
   - `Esc` — Закрыть модальное окно / Выйти из полноэкранного режима

---

## 🚀 Как запустить

### Вариант 1: Быстрое открытие
Просто откройте файл `index.html` в любом браузере (Google Chrome, Яндекс.Браузер, Microsoft Edge, Safari, Firefox) двойным кликом мыши.

### Вариант 2: Локальный веб-сервер (по желанию)
Если установлен Node.js или Python:

```bash
# Через Python:
python -m http.server 8080

# Или через Node.js:
npx serve .
```
Затем перейдите по адресу: [http://localhost:8080](http://localhost:8080).
